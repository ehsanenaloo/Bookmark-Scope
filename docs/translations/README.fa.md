# Bookmark Scope

**بوکمارک‌های سایتی که در آن هستید را پیدا کنید. بقیه‌ی کتابخانه‌تان را مرتب کنید.**

یک افزونه‌ی رایگان Chrome برای کسانی که بیش از حد لینک ذخیره کرده‌اند.<br>

## چرا این افزونه ساخته شد

Chrome بوکمارک‌های شما را به شکل درخت پوشه نشان می‌دهد. برای بیست لینک این کافی است. برای دو هزار لینک نه.

یک مقاله را سه بار ذخیره کرده‌اید. نصف لینک‌های یک پوشه‌ی سال 2019 دیگر کار نمی‌کنند. یازده بوکمارک از یک سایت دارید و آن یکی را که می‌خواهید پیدا نمی‌کنید. Bookmark Scope برای همین مشکل‌ها ساخته شده.

- روی هر صفحه پنجره‌ی کوچک افزونه (popup) را باز کنید. بوکمارک‌هایی را می‌بینید که از قبل برای همان صفحه، همان میزبان یا همان دامنه دارید.
- داشبورد را باز کنید. کل کتابخانه‌تان را می‌بینید، تکراری‌ها و لینک‌های مرده را پیدا می‌کنید و با چند کلیک درستشان می‌کنید.

## چه کارهایی می‌توانید بکنید

### ببینید برای این سایت چه چیزی ذخیره کرده‌اید

روی آیکون نوار ابزار کلیک کنید. پنجره‌ی کوچک افزونه بوکمارک‌های صفحه‌ای را که در آن هستید فهرست می‌کند. می‌توانید بین همین صفحه، همین میزبان یا کل دامنه جابه‌جا شوید. نشان (badge) روی آیکون نشان می‌دهد چند بوکمارک مطابقت دارد.

### کل کتابخانه‌تان را ببینید

داشبورد یک صفحه‌ی کامل برای بوکمارک‌های شماست. بر اساس عنوان، نشانی یا پوشه جست‌وجو کنید. بر اساس دامنه یا پوشه گروه‌بندی کنید. بر اساس عنوان، نشانی یا تاریخ مرتب کنید. تکراری‌ها، بوکمارک‌های بدون عنوان، بوکمارک‌های قدیمی و عنوان‌های هم‌نام را فیلتر کنید. با هزاران بوکمارک هم سریع می‌ماند.

روی یک بوکمارک کلیک کنید تا جزئیاتش را ببینید. چند تا را تیک بزنید تا با هم رویشان کار کنید. بوکمارک‌ها را بکشید تا ترتیبشان عوض شود.

### بدون نگرانی مرتب کنید

هیچ کار بزرگی بدون پیش‌نمایش انجام نمی‌شود.

<p align="center">
  <img src="../assets/screenshots/duplicate-preview.png" alt="پنجره‌ی پیش‌نمایش تکراری‌ها که در آن انتخاب می‌کنید کدام بوکمارک بماند" width="780">
</p>

- **تکراری‌ها.** خودتان انتخاب می‌کنید کدام نسخه بماند. برچسب‌های نسخه‌های دیگر به آن اضافه می‌شود. نتیجه را می‌بینید، بعد چیزی پاک می‌شود.
- **برچسب‌ها.** برچسب‌ها را برای چند بوکمارک با هم اضافه، حذف، تغییر نام یا ادغام کنید. قبل و بعد را ببینید، بعد اعمال کنید. می‌توانید لغوش کنید.
- **حذف و بازگردانی.** بوکمارک‌های حذف‌شده را می‌شود با برچسب‌هایشان برگرداند. Chrome اجازه نمی‌دهد هیچ افزونه‌ای شناسه‌ی اصلی یا تاریخ افزودن را برگرداند، پس بوکمارک بازگردانده‌شده یک بوکمارک تازه است. افزونه این را به شما می‌گوید.

### لینک‌های مرده را پیدا کنید

یک گروه از بوکمارک‌ها را بررسی کنید تا ببینید کدام لینک‌ها کار می‌کنند، کدام به جای دیگری می‌روند (ریدایرکت) و کدام خراب‌اند. بررسی در مرورگر شما اجرا می‌شود و فقط با سایت‌هایی که بوکمارک کرده‌اید ارتباط می‌گیرد.

- اول اجازه می‌خواهد. اگر قبول نکنید، بقیه‌ی امکانات همچنان کار می‌کنند.
- می‌توانید یک بررسی طولانی را متوقف کنید و بعداً ادامه دهید.
- می‌توانید بررسی زمان‌بندی‌شده را روشن کنید. به‌طور پیش‌فرض خاموش است.
- «ترمیم ریدایرکت‌ها» بوکمارک‌هایی را که به نشانی جدید رفته‌اند به‌روز می‌کند. لغو ندارد، پس اول نشانی جدید را ببینید.

### پشتیبان بگیرید و جابه‌جا کنید

- **اسنپ‌شات.** کل کتابخانه‌تان را، با پوشه‌ها و برچسب‌ها، در یک فایل ذخیره کنید. بعداً در یک پوشه‌ی جدید برگردانیدش.
- **درون‌ریزی.** بوکمارک‌ها را از Chrome، Edge، Firefox، Safari یا Brave (فایل `bookmarks.html`)، Pocket، Pinboard، Raindrop.io یا یک فهرست CSV، JSON یا متنی ساده از لینک‌ها وارد کنید. پیش‌نمایش می‌بینید و برای تکراری‌ها انتخاب می‌کنید: نگه داشتن، رد کردن یا ادغام.
- **برون‌بری.** بوکمارک‌هایی را که الان جلوی چشمتان است به‌صورت JSON یا CSV ذخیره کنید.

### سریع‌تر کار کنید

- **پالت فرمان.** `Ctrl+Shift+P` را بزنید (در مک `Cmd+Shift+P`) و کاری را که می‌خواهید بنویسید.
- **نماهای ذخیره‌شده.** یک جست‌وجو را با فیلترها، برچسب‌ها، مرتب‌سازی و گروه‌بندی‌اش ذخیره کنید. با یک کلیک دوباره بازش کنید.
- **منوی راست‌کلیک.** روی هر صفحه یا لینک، بوکمارک‌های آن دامنه را نشان بدهید یا تکراری‌های آن لینک را پیدا کنید.
- **یادآورهای مرور.** اگر می‌خواهید هر چند هفته یک بار برای مرتب کردن یادآوری بگیرید، در تنظیمات روشنشان کنید.

## نصب

**از Chrome Web Store (ساده‌ترین راه)**

1. [صفحه‌ی Bookmark Scope](https://chromewebstore.google.com/detail/cdonpinfefphkfdcffnangpmjjkoklfo) را باز کنید.
2. روی **Add to Chrome** کلیک کنید.
3. روی آیکون puzzle در نوار ابزار کلیک کنید و Bookmark Scope را پین کنید.

مرورگرهای Chromium دیگر مثل Edge و Brave معمولاً می‌توانند از همین صفحه نصبش کنند. من فقط با Chrome تست می‌کنم. Firefox و Safari پشتیبانی نمی‌شوند.

**از همین مخزن**

مرحله‌ی build ندارد. پوشه‌ی `extension` خودِ افزونه است.

1. این مخزن را دانلود یا clone کنید.
2. `chrome://extensions` را باز کنید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** کلیک کنید و پوشه‌ی `extension` را داخل مخزن انتخاب کنید (همان که `manifest.json` در آن است)، نه پوشه‌ی اصلی را.

نسخه‌ی unpacked شناسه‌ی افزونه‌ی خودش را دارد. می‌توانید کنار نسخه‌ی Store نگهش دارید، ولی داده‌هایشان مشترک نیست و نسخه‌ی unpacked خودش به‌روز نمی‌شود.

## داده‌های شما پیش خودتان می‌ماند

سرور وجود ندارد. حساب کاربری، آنالیتیکس و تبلیغ هم وجود ندارد. بوکمارک‌ها، برچسب‌ها و تنظیمات شما در مرورگر خودتان می‌ماند. جزئیات در [سیاست حریم خصوصی](../PRIVACY.md) آمده.

افزونه صفحه‌هایی را که می‌بینید نمی‌خواند. فقط نشانی تب فعال را می‌خواند تا بوکمارک‌های مطابق را نشان بدهد.

| مجوز | برای چه لازم است |
| --- | --- |
| `bookmarks` | خواندن بوکمارک‌های شما، و تغییر دادنشان وقتی خودتان بخواهید |
| `tabs` | خواندن نشانی تب فعال برای پنجره‌ی کوچک افزونه و نشان روی آیکون |
| `storage` | نگه داشتن تنظیمات، برچسب‌ها و نتیجه‌ی بررسی‌ها در مرورگر |
| `alarms` | اجرای یادآورها و بررسی‌های زمان‌بندی‌شده (هر دو اختیاری) |
| `notifications` | نشان دادن یادآورها و نتیجه‌ی بررسی‌ها |
| `contextMenus` | افزودن گزینه‌های منوی راست‌کلیک |
| `clipboardWrite` | کپی کردن نشانی‌ها وقتی روی دکمه‌ی کپی کلیک می‌کنید |
| `favicon` | نشان دادن آیکون سایت‌ها از حافظه‌ی نهان خود مرورگر |
| وب‌سایت‌ها (اختیاری) | فقط وقتی بررسی لینک را شروع می‌کنید پرسیده می‌شود، تا افزونه بتواند با سایت‌هایی که بوکمارک کرده‌اید تماس بگیرد |

## نکته‌های مهم

- **ترجمه‌ها.** ترجمه‌ها ماشینی هستند و ممکن است اشتباه داشته باشند یا بعضی کلمه‌ها انگلیسی مانده باشند. اگر زبان مادری‌تان یکی از این زبان‌هاست و می‌توانید ترجمه‌ی درست و طبیعی بنویسید، لطفاً به ما کمک کنید: [یک issue باز کنید](https://github.com/ehsanenaloo/Bookmark-Scope/issues) یا pull request بفرستید. جزئیات در [CONTRIBUTING.md](../../.github/CONTRIBUTING.md#translations).
- **درون‌ریزی تخت است.** وقتی فایل `bookmarks.html` را وارد می‌کنید، نام پوشه به‌صورت مسیر نشان داده می‌شود، ولی پوشه‌ای ساخته نمی‌شود و تاریخ‌های اصلی نگه داشته نمی‌شوند. اگر باید درخت پوشه‌ها را دوباره بسازید، از اسنپ‌شات استفاده کنید.
- **بررسی لینک فقط یک نشانه است.** هر پاسخ 4xx یعنی خراب. صفحه‌ای که باز می‌شود ولی خطا یا صفحه‌ی ورود نشان می‌دهد، سالم حساب می‌شود.
- **CSV.** خروجی CSV را با درون‌ریز خود افزونه و با یک دانلود واقعی در Chrome تست کرده‌ام. هنوز آن را در Excel، Numbers یا Google Sheets باز نکرده‌ام.
- **تست.** افزونه در Chromium تست شده. [فهرست کامل محدودیت‌ها](../guides/limits.html) را ببینید.

## میان‌برهای صفحه‌کلید

| کلیدها | چه کار می‌کند |
| --- | --- |
| `Ctrl+Shift+P` / `Cmd+Shift+P` | باز کردن پالت فرمان |
| `/` | رفتن به کادر جست‌وجو |
| `Ctrl+A` / `Cmd+A` | انتخاب همه‌ی بوکمارک‌های فهرست فعلی |
| `Esc` | یک قدم برگشتن: لغو ویرایش، پاک کردن جست‌وجو، پاک کردن انتخاب، بستن پنجره |

## به پروژه کمک کنید

گزارش خطا، اصلاح ترجمه و pull request های کوچک خوش‌آمدند. اول [CONTRIBUTING.md](../../.github/CONTRIBUTING.md) را بخوانید. قبل از فرستادن pull request، این بررسی را اجرا کنید. به Node.js نسخه‌ی 24 یا بالاتر نیاز دارد و نصب چیزی لازم نیست.

```bash
node scripts/validate.mjs
node scripts/test.mjs
```

لطفاً مشکل‌های امنیتی را خصوصی گزارش کنید. [SECURITY.md](../../.github/SECURITY.md) را ببینید.

اگر Bookmark Scope وقتتان را کم کرده، می‌توانید [برای من یک قهوه بخرید](https://buymeacoffee.com/enaloo). امتیاز دادن در [Chrome Web Store](https://chromewebstore.google.com/detail/cdonpinfefphkfdcffnangpmjjkoklfo) هم به دیده شدن افزونه کمک می‌کند.
