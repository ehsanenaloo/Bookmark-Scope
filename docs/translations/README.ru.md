# Bookmark Scope

**Находите закладки для сайта, на котором вы сейчас. Наводите порядок в остальных.**

Бесплатное расширение для Chrome для тех, кто накопил слишком много ссылок.<br>
Работает только на вашем компьютере. Без аккаунта и без слежки.

## Зачем это нужно

Chrome показывает закладки как дерево папок. Для двадцати ссылок этого хватает. Для двух тысяч уже нет.

Вы сохраняете одну и ту же статью три раза. Папка из 2019 года наполовину состоит из мёртвых ссылок. У вас одиннадцать закладок про один сайт, и нужную не найти. Bookmark Scope помогает с этими проблемами.

- Откройте всплывающее окно на любой странице. Вы увидите закладки, которые уже есть для этой страницы, этого сайта или этого домена.
- Откройте панель. Вы увидите всю библиотеку, найдёте дубликаты и мёртвые ссылки и исправите их за несколько кликов.

## Что можно делать

### Смотреть, что вы уже сохранили для этого сайта

Нажмите на значок на панели инструментов. Всплывающее окно покажет закладки для текущей страницы. Переключайтесь между этой точной страницей, этим хостом и всем доменом. Число на значке показывает, сколько закладок подходит.

### Видеть всю библиотеку

Панель открывается на отдельной странице, где собраны все ваши закладки. Ищите по названию, адресу или папке. Группируйте по домену или по папке. Сортируйте по названию, адресу или дате. Фильтруйте дубликаты, закладки без названия, старые закладки и совпадения названий. Она остаётся быстрой даже с тысячами закладок.

Нажмите на закладку, чтобы увидеть сведения о ней. Отметьте несколько, чтобы работать с ними вместе. Перетаскивайте закладки, чтобы менять их порядок.

### Наводить порядок без страха

Ничего серьёзного не происходит без предпросмотра.

<p align="center">
  <img src="../assets/screenshots/duplicate-preview.png" alt="Окно предпросмотра дубликатов, где вы выбираете, какую закладку оставить" width="780">
</p>

- **Дубликаты.** Выберите, какую копию оставить. Теги других копий добавятся к ней. Вы видите результат до того, как что-либо удалится.
- **Теги.** Добавляйте, удаляйте, переименовывайте и объединяйте теги сразу для многих закладок. Проверьте, как было и как станет, и примените. Это можно отменить.
- **Удаление и отмена.** Удалённые закладки можно вернуть вместе с тегами. Chrome не позволяет ни одному расширению вернуть исходный ID и дату добавления, поэтому восстановленная закладка получается новой. Расширение сообщает вам об этом.

### Находить мёртвые ссылки

Проверьте группу закладок и узнайте, какие ссылки работают, какие перенаправляют и какие сломаны. Проверка идёт в вашем браузере и обращается только к сайтам из ваших закладок.

- Сначала расширение просит разрешение. Если вы откажете, всё остальное продолжит работать.
- Долгую проверку можно поставить на паузу и продолжить позже.
- Можно включить проверку по расписанию. По умолчанию она выключена.
- «Исправить перенаправленные» обновляет закладки, которые переехали на новый адрес. Отменить это нельзя, поэтому сначала посмотрите на новый адрес.

### Резервные копии и перенос

- **Снимок.** Сохраните всю библиотеку вместе с папками и тегами в один файл. Позже восстановите её в новую папку.
- **Импорт.** Приносите закладки из Chrome, Edge, Firefox, Safari или Brave (файл `bookmarks.html`), Pocket, Pinboard, Raindrop.io, а также из CSV, JSON или обычного списка ссылок. Вы видите предпросмотр и сами выбираете, что делать с дубликатами: оставить, пропустить или объединить.
- **Экспорт.** Сохраните закладки, которые сейчас на экране, в JSON или CSV.

### Работать быстрее

- **Палитра команд.** Нажмите `Ctrl+Shift+P` (на Mac `Cmd+Shift+P`) и введите, что хотите сделать.
- **Сохранённые виды.** Сохраните поиск вместе с фильтрами, тегами, сортировкой и группировкой. Открывайте его снова одним кликом.
- **Контекстное меню.** На любой странице или ссылке показывайте свои закладки для этого домена или ищите дубликаты этой ссылки.
- **Напоминания о проверке.** Включите их в настройках, если хотите, чтобы раз в несколько недель вам напоминали навести порядок.

## Установка

**Из Chrome Web Store (проще всего)**

1. Откройте [страницу Bookmark Scope](https://chromewebstore.google.com/detail/cdonpinfefphkfdcffnangpmjjkoklfo).
2. Нажмите **Добавить в Chrome** (**Add to Chrome**).
3. Нажмите на значок пазла на панели инструментов и закрепите Bookmark Scope.

Другие браузеры на Chromium, например Edge и Brave, обычно могут установить расширение с той же страницы. Я тестирую только в Chrome. Firefox и Safari не поддерживаются.

**Из этого репозитория**

Сборки нет. Папка `extension` и есть расширение.

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `chrome://extensions` и включите **Режим разработчика** (**Developer mode**).
3. Нажмите **Загрузить распакованное расширение** (**Load unpacked**) и выберите папку `extension` внутри репозитория (в ней лежит `manifest.json`), а не верхнюю папку.

У распакованной копии свой ID расширения. Её можно держать рядом с версией из Store, но данные у них общие не будут, а сама распакованная копия не обновляется.

## Ваши данные остаются у вас

Сервера нет. Нет аккаунта, аналитики и рекламы. Ваши закладки, теги и настройки хранятся в вашем браузере. Подробности в [политике конфиденциальности](../PRIVACY.md).

Расширение не читает страницы, которые вы посещаете. Оно читает только адрес активной вкладки, чтобы показать подходящие закладки.

| Разрешение | Для чего оно нужно |
| --- | --- |
| `bookmarks` | Читать ваши закладки и менять их, когда вы просите |
| `tabs` | Читать адрес активной вкладки для всплывающего окна и числа на значке |
| `storage` | Хранить в браузере ваши настройки, теги и результаты проверок |
| `alarms` | Запускать необязательные напоминания и необязательные проверки по расписанию |
| `notifications` | Показывать напоминания и результаты проверок |
| `contextMenus` | Добавлять пункты в контекстное меню |
| `clipboardWrite` | Копировать адреса, когда вы нажимаете кнопку копирования |
| `favicon` | Показывать значки сайтов из собственного кэша браузера |
| Сайты (необязательно) | Запрашивается, только когда вы запускаете проверку ссылок, чтобы расширение могло обращаться к сайтам из ваших закладок |

## Что стоит знать

- **Переводы.** Переводы сделаны машиной, поэтому в них могут быть ошибки или остаться английские слова. Если один из этих языков для вас родной и вы можете написать правильный, естественный перевод, помогите нам: [откройте issue](https://github.com/ehsanenaloo/Bookmark-Scope/issues) или отправьте pull request. Подробности в [CONTRIBUTING.md](../../.github/CONTRIBUTING.md#translations).
- **Импорт плоский.** При импорте файла `bookmarks.html` название папки показывается как путь, но сами папки не создаются, а исходные даты не сохраняются. Если нужно воссоздать дерево папок, используйте снимок.
- **Проверка ссылок даёт подсказки.** Любой ответ 4xx считается поломкой. Страница, которая загрузилась, но показывает ошибку или экран входа, считается рабочей.
- **CSV.** Я проверил экспорт в CSV импортёром и настоящей загрузкой в Chrome. Открыть его в Excel, Numbers или Google Sheets я пока не пробовал.
- **Тестирование.** Расширение тестируется в Chromium. См. [полный список ограничений](../guides/limits.html).

## Горячие клавиши

| Клавиши | Что делают |
| --- | --- |
| `Ctrl+Shift+P` / `Cmd+Shift+P` | Открыть палитру команд |
| `/` | Перейти в поле поиска |
| `Ctrl+A` / `Cmd+A` | Выделить все закладки в текущем списке |
| `Esc` | Вернуться на один шаг: отменить правку, очистить поиск, снять выделение, закрыть диалог |
