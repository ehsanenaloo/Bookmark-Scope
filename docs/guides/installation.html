Requirements#

  • Chrome with Manifest V3 extension support. Chromium-based browsers share the extension format, but this guide and the project’s recorded acceptance tests only cover Chromium/Chrome. Other browsers, including Firefox, are not verified.
  • No account and no sign-in. Bookmark Scope has no server component.

Option A: Chrome Web Store#

  1. Find it

    Open the Bookmark Scope – Domain & Page Manager listing in the Chrome Web Store. The project’s GitHub repository is the other place to confirm you have the right extension.

  2. Add it

    Choose Add to Chrome and read Chrome’s permission prompt before you confirm. The permissions Bookmark Scope declares are listed in Privacy, permissions and data.

  3. Pin it

    Open the Extensions menu (puzzle piece) and pin Bookmark Scope.

Older releases

This guide describes the current release. If Chrome’s install prompt asks for access to all websites up front, you are looking at an older release that predates the optional site-access model described in Link health. Update to a current release to match this guide.

Option B: Load unpacked (from source)#

Use this to try a build from the public repository, or to review exactly what runs.

  1. Get the files

    Download the repository as a ZIP from GitHub and extract it, or clone it with Git:

    git clone https://github.com/ehsanenaloo/Bookmark-Scope.git

  2. Open the extensions page

    Go to chrome://extensions and turn on Developer mode (top right).

  3. Load the folder

    Choose Load unpacked and select the folder that directly contains manifest.json, popup.html and dashboard.html.

You should see: a card named Bookmark Scope – Domain & Page Manager with the version number and no error badge. If Chrome shows Manifest file is missing or unreadable, you selected a folder one level too high or too low.

Note

An unpacked copy gets its own extension ID, so it can be installed next to the Web Store version. The two do not share data: tags, saved views and settings are separate. An unpacked extension also depends on the folder staying where it is. If you move or delete the folder, Chrome disables the extension. Your bookmarks are never affected, but see Uninstalling and your data for what happens to Bookmark Scope’s own data.

Pinning and quick access#

Pin the extension from the Extensions menu. Chrome also lets you assign a keyboard shortcut to an extension’s toolbar button at chrome://extensions/shortcuts. That is a Chrome feature rather than something Bookmark Scope adds, and Bookmark Scope does not ship a default shortcut.

Updating#

How you installedHow it updates
Chrome Web StoreChrome updates it automatically in the background. To check now, open chrome://extensions, turn on Developer mode and use Update.
Load unpackedReplace the folder contents (or run git pull), then press the reload icon on the extension’s card.

Your data survives updates. On startup Bookmark Scope checks its stored data format (currently schema version 7), fills in defaults for anything new and keeps your tags, saved views, history and preferences. One deliberate exception: cached link-health results from before a format change may be discarded and are rebuilt the next time you run a scan. They are only a cache.

Uninstalling and your data

To remove the extension, open chrome://extensions and choose Remove.

WhatAfter you uninstall
Your bookmarks, folders and their orderUnchanged. They belong to the browser, not to the extension.
Bookmark Scope tags, saved views, link-health results, history, settings, recovery journalsRemoved. Chrome deletes an extension’s stored data when it is uninstalled. Tags are stored by the extension, not in the bookmark itself, so they do not survive.
Optional site access you granted for link checksRemoved together with the extension.
Before you uninstall

If you want to keep your tags, export a snapshot first (Library tools → Export snapshot). A snapshot file includes your folder tree and tags. See Backup and restore.

Clearing only some data

  • Link-health cache: Library tools → Clear cached health data. Bookmarks are untouched.
  • Preferences: Settings → Reset defaults restores nine preferences (see Settings reference). It does not remove tags, saved views, history or scan settings.
  • Site access: revoke it any time from the extension’s Details page at chrome://extensions. The exact wording of Chrome’s site-access controls is up to Chrome.
