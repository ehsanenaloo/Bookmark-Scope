Smart views

A smart view is a saved recipe for looking at your library. Open it later and it is recalculated against the bookmarks you have then.

What a view stores#

  • The search text (up to 2,000 characters).
  • The cleanup filter chip (All, Duplicates, Untitled, Old, Collisions).
  • The tag filter (tags you had switched on).
  • The sort order, the grouping and the group order.

It does not store bookmark titles, addresses, IDs or the selection. Views are live: if you add three new bookmarks that match a saved recipe, they appear next time you open it.

You can keep up to 50 views. Names can be up to 80 characters.

Create a view#

  1. Set the dashboard up

    For example search domain:example, choose the Old chip and Group by folder.

  2. Open the dialog

    Library tools → Saved views.

  3. Name and save

    Type a View name and choose Save view. The dialog confirms with View saved and keeps that view selected, so saving again updates it rather than creating a duplicate.

Open, update or delete a view#

  • Pick it in the Saved views list, then choose Open view. The dashboard applies the recipe, returns to the entire library and clears any selection.
  • To change a view, open it, adjust the dashboard, reopen Saved views, select the same view and press Save view.
  • Delete view removes it (the bookmarks are unaffected). Open view and Delete view stay disabled until a real saved view is selected.
