Bookmark Scope shows at most three kinds of notification. Here is what triggers each one, and how to set up review reminders.

All notifications#

NotificationWhen it appearsHow to turn it off
Pin Bookmark Scope for faster accessOn a fresh install, and again at browser start while the pin hint has not been dismissedChoose Got it on the Quick setup card in the dashboard or popup
Bookmark Scope: new broken links foundAfter a scheduled background scan finds bookmarks that newly look brokenTurn off the scheduled scan in Settings
Bookmark Scope review is dueWhen a review reminder is enabled and its next date has passedUntick Enable review reminders in Settings

Notifications use Chrome’s notification system, so your operating system’s focus or do-not-disturb settings can hide them. That is operating-system behavior, not something Bookmark Scope controls.

Review reminders: what they are for#

A review reminder is a gentle nudge to open the dashboard every N days. It only shows a notification, titled Bookmark Scope review is due, that mentions the date the review was scheduled for. It does not scan, change or delete anything, and it needs no site access.

Turn them on#

  1. Open Settings

    Use the popup’s More controls menu or the dashboard’s More actions menu and choose Settings.

  2. Find the Review reminders section

    Tick Enable review reminders (off by default) and set Reminder interval (days), from 1 to 365 (default 14).

  3. Save

    Choose Save settings.

What you doWhat happens to the schedule
Enable reminders for the first timeThe first reminder is scheduled interval days after your last recorded review, or after now if you have never recorded one. If that moment has already passed, it is set interval days from now
Save again without changing the intervalThe schedule does not move
Change the interval and saveThe schedule is re-anchored: last review date plus the new interval (or from now if that is already past)
Untick the box and saveReminders stop and the pending alarm is cleared
A reminder firesYou get the notification, and the next one is scheduled one interval later

A value outside 1–365 is corrected when you save. The background worker re-arms its timer whenever these settings change, and reminders can only fire while the browser is running.

Mark reviewed now#

Open the dashboard’s Health panel and choose Mark reviewed now after you have gone through your library. It records the review in the Activity log. If reminders are on, it also moves the next reminder to one interval from now and shows Review marked complete. Next reminder …. If reminders are off it only logs the review. The dashboard footer and the Health panel show the state: reminders off, Next review in N days or Review due. When a review is due, the Stats panel also offers a Scheduled review is due recommendation.

If you also want link checks#

Use the scheduled background scan. It is separate: it needs site access, runs on its own timer and notifies you only when it finds something new.
