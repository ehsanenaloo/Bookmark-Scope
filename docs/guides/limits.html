How to read this page#

These limits were checked against the source and, where noted, by running the extension in a disposable Chromium profile with synthetic bookmarks. They may change in a later release.

Hard limits and design boundaries#

AreaLimit
BrowsersTested in Chrome and Chromium. Edge and Brave can add it from the Chrome Web Store page; it is not listed on Edge Add-ons yet. Firefox 140 or newer on desktop has an experimental build (tested on Firefox 157 on Windows, not on Firefox Add-ons yet, see the installation guide). Safari is not supported.
PagesOnly http and https addresses are matched, checked or imported.
FoldersBookmark Scope cannot create, rename or delete folders (except the single new folder a snapshot restore creates). Use Chrome’s bookmark manager.
UndoDelete and move Undo recreate or reposition bookmarks but cannot restore original IDs or dates added. Undo exists only for the open page. Redirect repair has no Undo.
AtomicityOperations that touch many bookmarks are not all-or-nothing. A partial result is reported and recovered item by item.
Tags32 characters each, 20 per bookmark. Stored only on this browser profile, not synced, not part of Chrome’s bookmark data.
Old thresholdFixed at 730 days.
Link-health timeouts8 seconds per request, 5 for the GET fallback.
Health cache7 days; 5,000 results.
Scheduled scanUp to 250 addresses per run, interval 1–90 days; runs only while the browser is running.
Resumable scanBetween 1 and 50,000 addresses; one saved job; runs only while the dashboard is open.
Import / restore size10 MB for import files, 10 MiB for snapshots; snapshots up to 50,000 items and 100 folder levels.
Saved viewsAt most 50; names up to 80 characters.
Journals and history20 recent completed journals, 60 activity entries, 200 diagnostic events.
Popup listShows 8 rows.
SearchSubstring matching; no quoted phrases, no tag operator, no regular expressions. Fuzzy matching only in the popup.
Cross-deviceNo sync of Bookmark Scope data.

Not verified in a real browser#

  • Chrome’s actual permission prompt for site access, and live link checks against real websites (the project’s automated tests use controlled replacements).
  • Screen-reader output, measured colour contrast and zoom behavior.
  • Drag and drop with a touch screen.
  • Translation quality in languages other than English and Persian.
  • Behavior after the browser is killed mid-operation (a crash between creating a bookmark and writing its journal can leave an unjournaled bookmark).

Scope shortcuts and the right-click menu

  • The right-click entries open a dashboard that is already narrowed to one address’s domain or page. There is no on-screen control to change that scope; the keys 1, 2 and 3 do, and only in a dashboard opened that way.
  • On a dashboard opened normally, those keys show This page is not supported and an empty list. Reload to recover.

Link health

  • Any 4xx is “Broken”, including 401, 403 and 429. Treat the status as a hint.
  • A true redirect is not always a better address. A redirect to a sign-in page, a consent page or a homepage still counts as Redirected. Repair redirected has no Undo, so read Redirects to first.
  • The check judges the response headers only. A page that loads but shows an error message, a login wall or a consent page is still “Healthy”.
  • Skipped: Chrome Web Store addresses and non-web schemes.
  • The prompt for site access calls it “temporary”, but Bookmark Scope does not revoke it afterwards.

Import and export#

  • Browser bookmarks.html files (Netscape format: Chrome, Edge, Firefox, Safari, Brave and most bookmark managers) are imported as a flat list. Each row shows its folder path, but the folders are not recreated, and the added date and the icon are not imported. Addresses that are not http or https (bookmarklets, place:, about:, file:) are excluded. At most 50,000 bookmarks and 100 folder levels are read from a file of up to 10 MB. The reader is a small tolerant tokenizer, not a full HTML engine, and was checked with synthetic Chrome-style and Firefox-style files rather than real exports from every browser.
  • Imports are flat: folder paths and added dates in the file are descriptive only.
  • Restores are additive and are not deduplicated; repeating one creates a second copy.
  • The HTML reader for Pocket exports is a lightweight parser, not a full HTML engine.
  • The dashboard exports the visible list only, as JSON or as CSV; there is no export of just the selected bookmarks.
  • The CSV export has been checked against this project’s own importer and in a real Chromium download, but has not been opened in Excel, Numbers or Google Sheets. It starts with a UTF-8 byte-order mark so that spreadsheets read non-Latin text. A cell that could be read as a formula begins with an apostrophe; a spreadsheet may show that apostrophe, and Bookmark Scope removes it again on import.

Languages#

  • Some newer strings, including parts of the Library tools dialogs and the newest Settings options, appear in English until their translations are reviewed.
  • Translations for other languages have not had native-speaker review.

Reporting problems#

Open an issue on GitHub. A diagnostic export is safe to attach; snapshots and journals are not.
